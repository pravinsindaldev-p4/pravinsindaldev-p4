## About me

I build **hardware + software** that people can actually use — from ESP32 IoT labs for students to production web products for industry.

- Founder of **STC Creative Club** — STEM workshops, robotics & maker culture in Navsari / Dang
- Shipping **ZORVEXA ID** — dual-app ID card ERP (Industry + Master) on Firebase
- Hands-on with **ESP32 / ESP8266**, sensors, dashboards, React & Firebase
- Open to collabs on **IoT education**, school labs, and real product builds
